# 物理级双端架构隔离重构方案 (Desktop & Mobile Physical Isolation Plan)

## 1. 系统架构蓝图与目录划分

为彻底解决电脑端键鼠逻辑与手机竖屏触控手势的冲突，本次重构采用**底层数学内核共享 + 双端 UI 与交互组件树物理级完全隔离**的架构：

- **底层共享层（严禁修改数学逻辑）**
  - `src/types/cad.ts`：跨端统一的图元、图层、捕捉、三维 CSG 原语、多解候选与诊断数据结构（补充 `'pan'` 手型平移工具枚举类型）。
  - `src/utils/geometryKernel.ts`：三视图投影合法性诊断、手绘细虚线逆向解析、知二求三 CSG 推导与 HLR 消隐算法。
  - `src/utils/csgPrimitives.ts`：三维基础原语、SDF 场采样与网格离散构建逻辑。
  - `src/data/exerciseBank.ts`：经典工程制图题库数据。

- **根路由与共享状态容器（`src/App.tsx`）**
  - 仅负责维护跨端共享的核心工程数据（`entities`、`primitives`、`candidateSolutions`、`activeSolutionIndex`、`diagnostics`、Undo/Redo 历史栈、题库状态）以及 SVG / DXF / PNG / STL / JSON 导出与 AI 几何诊断流水线。
  - 自动检测视口宽度与设备触控特征（窄屏 `< 768px` 或移动终端默认进入 `MobileApp`，宽屏默认进入 `DesktopApp`），并提供一键切换至手机端/电脑端的入口。
  - 当在宽屏电脑端预览界面切换至 `MobileApp` 时，自动渲染带真实手机边框的居中竖屏容器（`9:19.5` 比例，`412×892px` 自适应高度，顶部带切换为「全屏铺满 / 手机外壳」开关与「返回电脑版」按钮）；在真实手机竖屏下自动 `100dvh` 全屏无边框铺满。

- **双端下载与导出中心（`src/components/DualDownloadModal.tsx`）**
  - 电脑端与手机端顶部栏共用弹窗，分为三大专区：
    1. **💻 电脑端下载专区（Windows `.exe` 桌面工作站）**：提供离线便携版构建与启动指南、一键下载工程源码配置包及当前 CAD 工程文件。
    2. **📱 手机端下载专区（Android `.apk` / 移动 PWA 离线安装）**：提供手机浏览器扫码/链接直达、Android APK 封装说明及 iOS/Android「添加到主屏幕」原生全屏运行指南。
    3. **📄 图纸与三维模型导出**：一键导出国标三视图 SVG 矢量图、AutoCAD DXF、高清 PNG 图纸、3D 打印 STL 实体网格及 JSON 工程存档（及导入工程文件）。

- **电脑端专用工作站（`src/desktop/DesktopApp.tsx` + `src/components/CadViewport2D.tsx`）**
  - 完整保留 PC 端 AutoCAD 风格四宫格大屏布局（主视图、俯视图、左视图、45° 宽相等辅助线 + 3D 视窗）、鼠标精准绘图、滚轮光标中心缩放、中键/右键平移及键盘快捷键（`1-4` 切换线型、`Delete/Backspace` 删除、`Ctrl+Z/Y` 撤销重做、`Ctrl+C/V` 复制粘贴）。
  - 清理所有手机端条件分支样式，确保 PC 端布局纯粹、零冗余。

- **手机端专用竖屏触控前端（`src/mobile/MobileApp.tsx` + `src/mobile/MobileCadCanvas2D.tsx`）**
  - 专为 `100dvh` 手机竖屏（Portrait `9:16 ~ 9:20`）与拇指热区设计，采用**三段式纵向布局**与**独立触控手势状态机**：
    1. **顶部精简导航栏**：左侧 `Dor.ED` 标志与 `[自由 | 题库]` 模式切换；居中高对比度 **【撤销 Undo】** 与 **【重做 Redo】** 按钮；右侧 **【诊断】**、**【推导】** 主按钮及更多菜单（含【双端下载/导出】、【清空画布】、【切换至电脑版】）。
    2. **可折叠「三等关系对齐联动窗」（上方参考带，默认展开，约占 `20%~22% dvh`）**：并排显示其余两个正交视图的实时缩略预览窗 + 迷你 3D 预览窗；当手指在主画布移动时，上方参考窗同步绘制蓝色/橙色动态投影对齐射线（实时直观呈现“长对正、高平齐、宽相等”）。
    3. **中央全宽主工作视口（约占 `55%~68% dvh`）**：
       - 顶部高对比度视图切换标签栏：`[ 主视图 (X-Z) | 俯视图 (X-Y) | 左视图 (Y-Z) | 3D 立体 ]`。
       - 左上角悬浮半透明 HUD：实时显示 `(X, Y, Z)` 精确坐标与当前捕捉状态（如 `已捕捉：端点 (60, 40)`）。
       - 底部悬浮横向滚动多解切换胶囊条：`[解1 | 解2 | 解3]`（当存在欠约束多解时浮现），以及选中图元时的快捷操作条（复制、改线型、删除）。
    4. **底部双层拇指操作坞（Bottom Thumb Dock）**：
       - **上层（线型与捕捉条）**：`[粗实线 | 细虚线 | 细点画线 | 辅助线]` 快捷切换 + `【捕捉设置】` 弹出面板（含网格、端点、中点、圆心、象限、交点开关与正交锁定开关）+ `【100% 复位】` 按钮。
       - **下层（横向滑动绘图工具栏）**：`[选择 | 手型平移 | 直线 | 矩形 | 多边形 | 圆 | 圆弧 | 切线 | 修剪 | 延伸 | 偏移 | 擦除]`，所有按钮严格保证 `>= 44×44px` 触控热区。

## 2. 手机端原生触控绘图与手势状态机设计（`src/mobile/MobileCadCanvas2D.tsx`）

1. **双模式绘图（「两次点按定起止」+「按住拖拽实时预览」双兼容）**
   - 绘制直线、矩形、圆、圆弧、切线时：
     - **点按模式（Tap-Tap）**：第一次轻触定起点/圆心，第二次轻触定终点/半径（若绘制圆弧则第三次轻触定终止角）。
     - **拖拽模式（Press-Drag-Release）**：手指按下定起点并直接滑动超过 `8px` 时实时预览几何图形，松手立即生成图元；画布右上角同步提供悬浮 **【完成 / 取消当前绘制】** 微型按钮（支持多边形闭合或随时中止）。
2. **触控防遮挡十字准星偏移（`36px` Touch Offset Crosshair & Magnifier HUD）**
   - 单指在画布上触摸或拖拽绘图/选点时，实际捕捉点与十字准星自动显示在手指触点正上方 **`36px`** 处，并附带高亮连线与顶部悬浮坐标气泡，彻底解决手指肚遮挡目标端点的问题。
3. **原生双指捏合缩放（Pinch-to-Zoom）与手型平移（Pan）**
   - 画布原生监听 Touch 多指事件：双指捏合围绕双指中心平滑缩放（`0.5x ~ 4.0x`），双指拖动平滑移动画布。
   - 单指处于 **「手型平移（Pan）」** 工具时，单指拖拽直接平移图纸，绝不误触画线；配合一键 **「复位视图（100% 居中）」** 按钮随时找回图纸中心。

## 3. 分阶段实施步骤

- **Phase 1：扩展工具类型与创建双端下载弹窗（`src/types/cad.ts`, `src/components/DualDownloadModal.tsx`）**
  - 在 `ToolType` 中加入 `'pan'` 手型平移工具。
  - 实现包含电脑端 `.exe` 指南/工程包下载、手机端 `.apk` / PWA 离线安装指南与二维码、以及 5 种格式（SVG / DXF / PNG / STL / JSON）导出与导入的 `DualDownloadModal.tsx`。
- **Phase 2：构建独立手机端触控画布与手机竖屏前端（`src/mobile/MobileCadCanvas2D.tsx`, `src/mobile/MobileApp.tsx`）**
  - 实现 `MobileCadCanvas2D.tsx`（含双指缩放平移、36px 防遮挡偏移准星、点按+拖拽双模式绘图、缩略参考模式 `compact` 渲染与跨视图投影射线）。
  - 实现 `MobileApp.tsx` 三段式竖屏布局、默认展开的上方「三等关系对齐联动窗」、题库抽屉、诊断与 AI 抽屉、多解胶囊条与底部双层拇指操作坞。
- **Phase 3：构建独立电脑端工作站与根容器路由（`src/desktop/DesktopApp.tsx`, `src/components/CadViewport2D.tsx`, `src/App.tsx`）**
  - 在 `CadViewport2D.tsx` 中支持 `'pan'` 工具并移除移动端冗余分支。
  - 将 PC 端四宫格工作站封装进 `src/desktop/DesktopApp.tsx`。
  - 重构 `src/App.tsx` 为跨端状态与双端切换根容器，支持在电脑端右侧预览窗内以 `9:19.5` 仿真手机外框或全屏模式流畅测试 `MobileApp`。
- **Phase 4：编译、静态检查与运行验证**
  - 执行 `compile_applet` 与 `lint_applet` 校验零错误并重启开发服务器。
